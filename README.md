# Quran Hifz Tracker (Client)

React + Vite frontend for Quran Hifz Tracker.

## Setup

1. Install
   - `npm ci`
2. Configure env
   - Copy `.env.example` to `.env`
   - Set `VITE_API_URL` (example: `http://localhost:4000`)
3. Run
   - `npm run dev`

## Build

- `npm run build`
- `npm run preview`
